# gfcgames.com

Site da GFCGAMES (GitHub Pages, sem build: HTML/CSS estáticos).

- `index.html` — página inicial (PT/EN na mesma página; `assets/lang.js` escolhe pelo navegador e lembra a escolha).
- `cafe-sort/privacidade/` — política de privacidade do Café Sort (é a URL que vai no Play Console).
- `app-ads.txt` — autorização de vendedores do AdMob (`pub-1450917092522809`). Tem que ficar na raiz do domínio
  que está como "site do desenvolvedor" na ficha da Play Store.
- `CNAME` — domínio próprio do GitHub Pages.
- Fonte Lilita One (SIL OFL 1.1, licença em `assets/fonts/OFL.txt`); imagens vêm de `cafe-sort/art/store`.
